Features

Everything you need on sea days

Built for the ship, not the shore. All data is yours — no mock cruises, no cloud sync, no surprise roaming.

🗓️

Cruise & daily planner

Create a cruise by ship name + calendar range. Duration auto-calculated, day-by-day planner auto-generates. Add/edit/delete events with title, time, location, category & reminder.

  • DateRangePicker & DatePicker
  • Sea vs port badge
  • Category + reminder 1–60 min
📍

Real port stops

Search any city via Open-Meteo Geocoding — free, no key — and auto-fill lat/lon. Stored in Room PortStop with arrival/departure & country.

  • lat/lon auto-fill
  • Order index preserved
  • Arrival/departure dates
🌤️

Weather — no API key

api.open-meteo.com/v1/forecast with daily + current. Cached in WeatherCache 3h TTL → works offline after first fetch.

  • 7-day daily + current
  • WMO code → emoji
  • Attribution CC BY 4.0
⏰

Local notifications

AlarmManager.setExactAndAllowWhileIdle per event on cruise_reminders channel. Re-scheduled on BOOT_COMPLETED.

  • High importance + vibrate
  • SCHEDULE_EXACT_ALARM
  • POST_NOTIFICATIONS (13+)
💬

Offline party chat

Google Nearby Connections P2P_CLUSTER — Bluetooth + BLE + Wi-Fi Direct, encrypted, no internet. Individual or broadcast with retry-until-delivered.

  • WireMessage + receipts
  • PENDING → SENT → DELIVERED → READ
  • QR identity, no typing
📆

Calendar

DatePickerDialog + DateRangePicker with clickable OutlinedCard for start/end plus -1d/+1d fine adjust. startOfDay() at midnight.

  • Single & range pickers
  • -1d/+1d nudge
  • Midnight normalization
Offline chat deep dive

Party chat that works when the ship doesn't

Each member gets a persistent code (UUID) stored in cruise_party_prefs. My QR shows {"n":name,"c":code} via ZXing; Scan adds via Camera + ScanContract. No typed names → guaranteed identity.

To: EveryonePrivateQueued • retrying...Read ✓✓ blue #4FC3F7

Retry every 5s, delivery + read receipts, FlowRow chips with FilterChip selection, Scaffold bottomBar fixed — so the thread scrolls correctly.

How it works

Three taps to sea-ready

Works entirely offline after setup — Room is source of truth.

1

Create your cruise

Name your ship, pick start/end on the calendar. We generate every day in between.

2

Add ports & plans

Search Nassau or Cozumel → Use → Add Port. Then tap any day to add Welcome Dinner, excursions, etc.

3

Stay in sync offline

Share your QR with your party. Chat over Nearby — no ship Wi-Fi needed. Weather pulls once, then cached.

Architecture

Offline-first by design

Room v3 fallbackDestructive + Flow + viewModelScope. Weather via Retrofit + OkHttp + kotlinx.serialization. Nearby via P2P_CLUSTER.
